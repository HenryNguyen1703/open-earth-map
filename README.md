# OpenEarthMap Semantic Segmentation

Research project for semantic segmentation on the OpenEarthMap dataset.

## Goal

Train and evaluate semantic segmentation models on OpenEarthMap.

Initial model:

- U-Net

## Project Structure

```text
open-earth-map/
├── configs/        # Training/model configuration
├── data/           # Dataset metadata, actual dataset is ignored
├── docs/           # Research notes and documentation
├── notebooks/      # Experiments and visualization
├── outputs/        # Training results and checkpoints
├── scripts/        # Executable scripts
├── src/            # Main source code
├── .gitignore
├── README.md
└── requirements.txt
